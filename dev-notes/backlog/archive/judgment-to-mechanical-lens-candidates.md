## The evidence shape
Three real judgment-class defects passed same-tier anneal verify clean and fell only to a
stronger cross-tier checker — yet each would ALSO have fallen to a cheap mechanical procedure
the lens set doesn't currently force:

1. **Domain-claim re-derivation.** Every claim binding the artifact to an external truth
   (statute text, calendar arithmetic, API contract) is re-derived in the falsification pass
   from the primary source — not read along. Sub-rule: **data beats commentary** (the author
   trusted a stale in-file comment contradicting the same file's own content). Would have
   caught: the legally-overclaiming message; the stale-comment grounding error.
2. **Worked-boundary-example obligation.** Every formula/predicate in a design carries at
   least one concretely traced boundary example before it counts as designed
   (01.07.–30.07. inclusive = 30 days would have exposed the `bis−von < 30` fencepost).
3. **Closed-set sweep.** Every closed value set the design touches is enumerated against its
   schema definition — each member either handled or loudly not-covered (would have caught the
   unhandled fourth enum literal and the ignored catalog field).
